# Toolkit badges

Local SVG snapshots generated with [Shields.io](https://shields.io/badges/static-badge), using its `for-the-badge` style and [Simple Icons](https://simpleicons.org/) logos. The profile has no runtime dependency on either service.

Each badge retains an accessible technology name and an embedded vector logo. Individual images wrap naturally on narrow screens. Java uses the OpenJDK logo. Technology names and logos belong to their respective owners.

Label text uses white (`#ffffff`) or near-black (`#111111`), whichever has greater contrast against the background. All labels meet a minimum 4.5:1 contrast ratio. After regenerating a badge, apply this color to the text group's `fill`; keep the embedded logo unchanged.

To regenerate a badge, use this URL format and save the response over its local SVG:

```text
https://img.shields.io/badge/{label}-{hexColor}?style=for-the-badge&logo={slug}&logoColor={logoColor}
```
